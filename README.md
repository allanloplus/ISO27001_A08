# ISO 27001:2022 威脅與弱點管理 — 動畫教學簡報

控制屬性「運作能力（Operational capabilities）」中 **Threat and vulnerability management** 主題課程，
以 Q 版 **Allan Lo 講師**（台灣男聲）與 **助教阿拉蕾** 雙角色對話方式，串起：

```
蒐集威脅資訊 ─分析→ 5.7 威脅情資 ─評估→ 8.8 技術脆弱性管理（採取措施）
└──────────────── 5.37 書面紀錄之運作程序 ────────────────┘
```

## 課程結構（24 頁，約 15 分鐘）

| 段落 | 頁 | 內容 |
|---|---|---|
| 開場 | 1–4 | 封面、課程地圖、全景流程圖、三個控制措施一句話記住 |
| PART 1 ISMS 作業重點 | 5–12 | 5.7 情資三層次／來源／生命週期、8.8 五步驟、修補時限與補償措施、5.37 程序要素、**案例①** SSL VPN 漏洞勒索事件 |
| PART 2 稽核查核重點 | 13–17 | 一條漏洞追到底（Trace audit）、查核清單、抽樣技巧（清冊 vs 弱掃、弱點帳齡）、**案例②** Log4Shell 與 SBOM |
| PART 3 常見缺失 | 18–21 | 八大缺失、不符合事項寫法（要求／事實／證據、Major/Minor）、**案例③** EOL 產線電腦風險接受 |
| 收尾 | 22–24 | 小測驗、三句口訣、結尾 |

## 使用方式

- **影片**：`video/TVM_威脅與弱點管理.mp4`（1280×720，含旁白與字幕，可直接上課播放或上傳平台）
- **互動簡報**：用瀏覽器開啟 `index.html`（建議透過本機伺服器，例如 `npx http-server .`），
  按「▶ 開始上課」。空白鍵播放／暫停、← → 換頁、C 開關字幕、F 全螢幕，下方進度列可點選跳轉。

## 修改講稿後重新產生

1. 編輯 `script.json`（`A` = Allan Lo 講師，`R` = 阿拉蕾；每頁的台詞順序對應 `index.html` 中元素的 `data-l` 出場時間）
2. 產生語音與時間軸：`pip install edge-tts && python3 tools/build_tts.py`
   - 講師：`zh-TW-YunJheNeural`（台灣男聲）；阿拉蕾：`zh-TW-HsiaoYuNeural`（調高音調與語速）
3. 輸出影片：`node tools/render_video.js video 20 4`（需 Playwright + ffmpeg；`snap` 模式可輸出每頁截圖檢查版面）

> 案例為教學改編之情境，不指涉特定組織；修補時限等數值為示意，應依組織風險胃納訂定。
